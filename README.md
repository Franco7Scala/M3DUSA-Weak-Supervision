# Toward Robust Multimodal Fake News Detection under Weak Supervision via Text-Derived Surrogate Labels

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

This repository contains the code and resources for the **M3DUSA-WS** framework presented in the research paper "Toward Robust Multimodal Fake News Detection under Weak Supervision via Text-Derived Surrogate Labels". Our proposal addresses the challenge of multimodal fake news detection in scenarios with limited ground-truth annotations by combining heterogeneous graph learning with text-derived surrogate labels and a consistency-regularized training strategy.

## Key Features

* **Weak Supervision Focus:** Exploits text-derived surrogate labels generated by a RoBERTa-based model trained on external datasets to compensate for extreme annotation scarcity;
* **M3DUSA-WS Framework:** Extends the M3DUSA early-fusion heterogeneous graph formulation with a dual-head learning mechanism to jointly model multimodal content and relational structures;
* **Consistency-Regularized Learning:** Employs a composite objective combining supervised classification, surrogate supervision, and consistency regularization to mitigate the impact of noisy weak labels;
* **Reproducibility:** Facilitates replication of our research results and robustness evaluations under varying levels of label scarcity.

## Repository Structure

* **`src/`**: Core source code directory.
  * `main_surrogate.py`: Main entry point to train and evaluate the M3DUSA-WS framework;
  * `models/gat_surrogate.py`: Contains the Heterogeneous Graph Neural Network (GATv2) architecture with dual classification heads;
  * `mixed_loss/`: Implements the combined objective function integrating supervised, surrogate, and consistency losses (`mixed_loss.py`, `binary_consistency_loss.py`);
  * `surrogate_model/`: Scripts to train the external RoBERTa classifier on external fake news datasets and extract surrogate labels;
  * `dataset/`: Utilities for dataset loading and multimodal embedding computation;
  * `training/trainer_surrogate.py`: Core training routines, including validation and early-stopping mechanisms;
  * `support/robustness.py`: Helper functions to simulate varying levels of annotation scarcity (label dropping) for robustness evaluation.
    
* **`requirements.txt`**: List of project dependencies.

## Requirements

To run the code, ensure you have the libraries specified in `requirements.txt` installed. The main dependencies include:

* Python (>=3.8)
* PyTorch
* PyTorch Geometric (PyG)
* Transformers (Hugging Face)
* NumPy
* Scikit-learn
